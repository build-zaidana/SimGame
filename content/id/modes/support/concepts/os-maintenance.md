**Sistem operasi** (OS) adalah program utama yang menjalankan komputer. Seperti kendaraan, OS perlu dirawat.

- **Disk penuh.** Di atas 90%, komputer melambat karena tidak ada ruang kerja. Hapus file sementara, kosongkan Recycle Bin, atau pindahkan file besar ke penyimpanan kantor.
- **Update.** Update keamanan menambal celah yang sudah diketahui penyerang. Menunda update berbulan-bulan sama dengan membiarkan pintu tidak terkunci. Pasang update resmi, lalu restart.
- **Driver.** Driver adalah "penerjemah" antara OS dan perangkat keras (printer, kartu grafis, Wi-Fi). Kalau masalah muncul **tepat setelah** driver diperbarui, kembalikan (**rollback**) ke versi sebelumnya.
- **Program saat startup.** Terlalu banyak program yang ikut menyala membuat komputer lama siap. Matikan yang tidak perlu.

Pasang aplikasi hanya dari **Portal Aplikasi** kantor. Aplikasi bajakan atau kiriman orang bisa membawa malware (program jahat).
