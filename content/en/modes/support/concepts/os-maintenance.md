The **operating system** (OS) is the main program that runs the computer. Like a vehicle, it needs care.

- **Full disk.** Above 90%, the computer slows down because there's no room to work. Delete temporary files, empty the Recycle Bin, or move big files to company storage.
- **Updates.** Security updates patch holes that attackers already know about. Putting off updates for months is like leaving the door unlocked. Install official updates, then restart.
- **Drivers.** A driver is the "translator" between the OS and hardware (printer, graphics card, Wi-Fi). If a problem appears **right after** a driver update, go back (**roll back**) to the previous version.
- **Startup programs.** Too many programs launching at startup make the computer slow to get ready. Turn off the ones you don't need.

Install apps only from the company **App Portal**. Pirated apps or files sent by strangers can carry malware (malicious programs).
