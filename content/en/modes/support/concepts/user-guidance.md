Not every ticket means something is broken. Often the device is **healthy**, but the user doesn't know how yet. Examples:

- The **Caps Lock** key is on, so the password is always "wrong".
- There's no sound because the speaker icon is _muted_.
- The monitor looks "dead", but the wrong input source is selected.

For cases like these, choose **Guide User**. Explain the steps one at a time in simple words, then ask the user to try it themselves. That way, next time they can solve it without waiting for a technician.

Taking apart a healthy device only wastes time and spare parts.

One important rule: **technicians never ask for passwords**. If a user forgets their password, point them to the official company reset page. Anyone who claims to be a technician and asks for a password deserves suspicion.

Finally, write the cause and the fix in the **ticket history**.
